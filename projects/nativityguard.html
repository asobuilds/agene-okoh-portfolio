🛡︝ NativityGuard

A digital operating layer for community-centered public safety — connecting grassroots observations and citizen participation to accountable, permission-controlled operational case management.

🧩 The Problem

In rural Nigerian communities, the gap between citizens and local security units is wide. Cases are handled informally, accountability is low, and response times suffer. There's no digital workflow for reporting incidents, tracking cases, or ensuring that follow-ups actually happen. The community lacks a transparent, auditable system for public safety.

💡 The Solution

NativityGuard links residents, community structures, security units/officers, and administrators through a single, auditable workflow: signal → intake → triage → routing → assignment → dispatch → arrival → investigation → evidence → resolution → audit → prevention.

  • Residents can report incidents, raise SOS alerts, submit evidence, and track case progress
  • Security units own cases for a geographic area, allocate officers, and run local oversight
  • Officers work assigned cases: dispatch, arrival, progress, evidence, closure
  • Intelligent map with crime indices and GIS functionality
  • Full audit trail, ratings, transfers, and community engagement (forum, announcements, events)
  • AI assistance via OpenRouter chat completions

⚙︝ Technical Architecture

  • API / system of record: Go 1.21 (module: security-solution) · Gin · GORM · PostgreSQL with UUID primary keys · JWT authentication
  • Web client: React 19 · Vite · Tailwind · lucide-react
  • Intelligence / automation tier (planned): Python · FastAPI · Celery · scikit-learn · GeoPandas · MLflow
  • Infrastructure: PostgreSQL · Redis · Docker Compose · Render.com
  • AI: OpenRouter chat completions for intelligent assistance
  • Real-time: WebSocket hub for live case updates and notifications
  • Domains: Cases · Evidence · Progress timeline · Officers · SOS alerts · Notifications (in-app/push/SMS/email) · Ratings · Finance · Peacebuilding trust scores · Video analytics · Communication (rooms, messages, calls) · Audit logs

🎯 Impact

NativityGuard digitalizes the entire workflow of how security units handle and settle cases. It promotes accountability, enables quick response, provides location tracing, and employs an intelligent map that shows crime indices with GIS functionality. It does not replace lawful security institutions and is explicitly designed not to encourage vigilantism.

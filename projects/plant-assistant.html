🌱 Plant Assistant

An AI-powered platform that democratizes agricultural knowledge for small-scale farmers.

PythonAI/MLStreamlitPWA

🧩 The Challenge

Farmers often lack access to quick, reliable plant information. Existing solutions are expensive, require constant internet, or aren't designed for real-world field conditions. The goal was to build something simple, visual, and resilient.

💡 The Solution

A Progressive Web App (PWA) using Python and a fine-tuned ML model for plant identification, with a geolocation-based advisory system. Users can snap a photo of any plant and receive instant identification, care advice, pesticide recommendations, and season-specific guidance. An integrated AI chatbot answers follow-up questions.

⚙️ Technical Highlights

  • Fine-tuned image classification model for regional plant species
  • Offline-first architecture using PWA service workers
  • Geolocation-aware advisory system for seasonal recommendations
  • Streamlit-based interactive prototype for rapid iteration

🔍 A Decision I'd Revisit

The initial prototype leaned heavily on Streamlit for rapid iteration, which was great for demos but limited mobile performance. If I rebuilt it today, I'd separate the ML inference API from the UI layer from day one — this would allow a leaner frontend and better offline support.

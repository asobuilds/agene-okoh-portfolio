🧩 The Challenge

My original portfolio was a single long page. Recruiters had to scroll forever, project links were buried, and there was no way to rank for anything in search. Worst of all: no clear call to action for potential clients. It was a résumé, not a business asset.

💡 The Solution

A complete ecosystem: landing page, dedicated service page, per-project case studies, a blog for build logs, a working contact form with email delivery, Google Analytics, SEO plumbing, and a design system shared across every page.

⚙️ Architecture

  • Multi-page structure: separate pages for Home, About, Experience, Projects, Services, Process, Contact, Writing, and 404
  • Project case studies: a dedicated page per project, including this one
  • Blog system: index + individual posts, each with its own meta description for SEO
  • Asset organization: assets/css/, assets/js/, assets/images/, assets/documents/
  • Vercel deploy: clean URLs, cache headers, security headers via vercel.json

🎨 Design System

  • CSS variables for colors, spacing, typography, shadows, and radii — one source of truth
  • Dark mode with localStorage persistence across pages
  • Custom loader with boot log (session-aware — only shows on first visit)
  • Terminal overlay (Ctrl + \`) with 10+ commands — a signature touch
  • Canvas particle system that respects prefers-reduced-motion and reduces density on mobile
  • Scroll-triggered animations via IntersectionObserver

📱 Responsiveness

Every page is tested and tuned for iPhone (with notch safe areas), Android, tablets, laptops, ultrawide, and 4K displays. Fluid typography uses clamp(), and all interactive elements respect @media (hover: none) so nothing "sticks" on touch devices.

🔍 SEO & Discovery

  • sitemap.xml with 17+ URLs, priority-weighted
  • robots.txt pointing Google at the sitemap
  • OpenGraph + Twitter Card meta tags on every page
  • Google Search Console property verified via meta tag
  • Sitemap submitted and accepted — pages indexing

📬 Contact Funnel

Contact form is wired to Formspree — submits land in my inbox within seconds. Direct links to WhatsApp, LinkedIn, GitHub, and X sit above the form so visitors can reach me on whichever channel they prefer.

📊 Analytics

Vercel Analytics is enabled — I can see which pages get visited, which project case studies recruiters open, and which blog posts land. Lightweight, privacy-respecting, no cookie banner needed.

🔍 A Decision I'd Revisit

I wrote the site as pure static HTML with a JS-injected header/footer. That was fast to build, but every new page needs its own file. If I rebuilt it today, I'd use Astro or 11ty — same static output, but shared layouts and content collections would make the blog 10× faster to maintain.

📈 Result

  • Live at agene-okoh.vercel.app
  • Zero-cost hosting on Vercel's global CDN
  • Sub-second load times on 4G
  • Working contact funnel + résumé download + analytics
  • Serves as both my portfolio and my live case study of full-stack delivery
